# Linux and Git Cheat Sheet 
 
## pwd
Purpose: Shows current directory 

## ls 
Purpose: Lists files/folder

## cd
Purpose: Change directory

## mkdir
Purpose: Create folder

## touch
Purpose: Create file

## cp
Purpose: Copy file

## mv
Purpose: Move/rename files

## rm
Purpose: Delete files

## cat
Purpose: Display file contents

## clear
Purpose: Clear terminal

## git init
Purpose: Initialize a Git repository

## git status
Purpose: Check respository status

## git log
Purpose: View commit history
